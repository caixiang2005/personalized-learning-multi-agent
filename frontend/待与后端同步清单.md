### 用户主流程（前端门禁，联调时需后端数据一致）

```
登录 → /home
  ├─ 未完成画像 → /profile-build（画像智能体）
  ├─ 已完成画像 → 驾驶舱
  ├─ 智能辅导 /chat → 未完成画像则重定向 /profile-build（fromTutorGate 提醒）
  └─ 学习路径 /path → 未完成画像则引导 /profile-build（fromPathGate 提醒）
        └─ /path/plan（路径智能体）→ 生成 → /path/view（阶段+五类资源）
```

**画像完成判定**（`lib/profileReady.ts`）：`learnerDimensions` 中至少一维 `source` 含「对话画像构建」或「用户手动更新」，或六维 `value` 均 &gt; 0。

| 功能 | 方法 | 路径 | 请求体 / 鉴权 | 页面 |
|------|------|------|---------------|------|
| 发注册验证码 | POST | `/api/user/sendRegEmailCode` | `{ email }` | Register |
| 注册 | POST | `/api/user/register` | `{ email, username, password, code }` | Register |
| 发登录验证码 | POST | `/api/user/sendLoginEmailCode` | `{ email }` | Login |
| 邮箱密码登录 | POST | `/api/user/login` | `{ email, password }` | Login |
| 用户名登录 | POST | `/api/user/loginByUsername` | `{ username, password }` | Login |
| 验证码登录 | POST | `/api/user/loginByEmailCode` | `{ email, code }` | Login |
| 用户信息 | GET | `/api/user/getUserInfo` | `Authorization: Bearer` | AuthBootstrap |
| 刷新 token | POST | `/api/user/refreshToken` | Header Bearer + body（见下） | `refreshToken()` 已封装 |
| 发重置验证码 | POST | `/api/user/sendResetEmailCode` | `{ email }` | ResetPassword |
| 重置密码 | POST | `/api/user/resetPwd` | `{ email, code, newPassword }` | ResetPassword |

**refreshToken**（已对齐）  
- 请求：`POST /api/user/refreshToken` + Bearer，body 可选 `{ refreshToken }`  
- 响应 `data`：`{ newToken, newRefreshToken }` · 前端 `user.ts` → `setTokens(data.newToken, data.newRefreshToken)`

**Vite 代理**（`vite.config.ts`，长前缀优先）：

## 七、Store 持久化（联调时注意）
