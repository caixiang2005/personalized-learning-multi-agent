### 用户主流程（前端门禁，联调时需后端数据一致）

```
登录 → /home
  ├─ 未完成画像 → /profile-build（画像智能体）
  ├─ 已完成画像 → 驾驶舱
  ├─ 智能辅导 /chat → 未完成画像则重定向 /profile-build（fromTutorGate 提醒）
  └─ 学习路径 /path → 未完成画像则引导 /profile-build（fromPathGate 提醒）
        └─ /path/plan（路径智能体）→ 生成 → /path/view（阶段+五类资源）
```

**画像完成判定**（`lib/profileReady.ts`）：`learnerDimensions` 中至少一维 `source` 含「对话画像构建」或「用户手动更新」，或六维 `value` 均 &gt; 0。

## 四、流式对话 SSE

| 场景 | 路径 | 前端 |
|------|------|------|
| 辅导（有 learn 会话） | `POST /api/chat/send/stream` | `Chat.tsx` → `sendChatMessageStream` |
| 辅导（无会话 / 兜底） | `POST /api/agent/chat/stream` | `agentChat.ts` → `streamAgentReply` |
| 非流式回退 | `POST /api/agent/chat` | `simulateStream` 打字 |
| 日计划侧边栏 | `POST /api/agent/chat/stream` | `PlanChatPanel` → `sendAgentMessage` |

事件格式：`{ type: "stage"|"token"|"resource"|"done", ... }` · 类型见 `endpoints.ts` → `StreamChunk`

| `type` | 含义 | 前端处理 |
|--------|------|----------|
| `stage` | 管道进度（检索/生成） | `StreamProgress` |
| `token` / `text` | 增量文本 | 追加到助手消息 |
| **`resource`** | RAG 检索到的视频/文档卡片 | `MultimodalCard` 列表 |
| `done` | 流结束 | 停止 loading |
| `error` | 错误 | 展示错误态 |

## 五、联调顺序建议

1. **user-service**：发码 → 注册 → 登录 → getUserInfo → getProfile / updateProfile / uploadAvatar / stats  
2. **agent-service 基础**：unlogin/chat → agent/chat（含 video RAG + 鉴权）  
3. **画像**：profile-build agent → `GET/PUT/PATCH /api/profile` 持久化六维画像  
4. **路径**：path-plan agent → generate（资源入库）→ `GET learning-path` → resource-status  
5. **资源详情**：`GET /api/resources/:id`、练习 ai-review → submit/save → 回写画像  
6. **评估 / 计划 / 搜题**：analytics、plan（含 toggle activity）、scan（结构化字段）  
7. **Chat RAG 卡片**：SSE 流中确认 `resource` 事件 → 助手消息下方卡片  
8. **可选**：chat/sessions、feedback、upload、safety/check  

**服务重启**：改动后需重启 learn-service（`:8002`）、agent-service（`:8003`）、user-service（`:8001`）。

## 七、Store 持久化（联调时注意）

`useAppStore` 通过 Zustand **persist** 写入 localStorage（key 与 theme 共用配置），目前持久化：

- `profile` · `profileInitialized` · `pathStages` · `learningPathMeta` · `pathPlanMessages`（规划对话）
- **未持久化**：`profileBuildMessages` · `tutorMessages` · `sessions`（刷新后丢失）

联调后建议：服务端为画像/路径/会话的权威数据源；前端 persist 仅作缓存或移除。
