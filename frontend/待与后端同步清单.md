## 〇、用户认证 V1.0 对照（`/api/user`）

基础路径：`/api/user` · 响应：`{ code, msg, data }` · 开发代理：**user-service `127.0.0.1:8001`**

| 文档接口 | 方法 | 前端路径 | 请求体（前端） | 页面/调用 | 核对 |
|----------|------|----------|----------------|-----------|------|
| sendRegEmailCode | POST | ✅ 一致 | `{ email }` | Register 发码 | ✅ |
| sendLoginEmailCode | POST | ✅ 一致 | `{ email }` | Login 验证码发码 | ✅ |
| sendResetEmailCode | POST | ✅ 一致 | `{ email }` | ResetPassword 发码 | ✅ 路由需后端实现 |
| register | POST | ✅ 一致 | `{ email, username, password, code }` | Register | ✅ |
| login/email | POST | ✅ 一致 | `{ email, password }` | Login 邮箱密码 | ✅ |
| login/username | POST | ✅ 一致 | `{ username, password }` | Login 用户名 | ✅ |
| login/code | POST | ✅ 一致 | `{ email, code }` | Login 验证码 | ✅ |
| refreshToken | POST | ✅ 一致 | `{ oldToken }` | 已封装，**页面未调用** | ✅ |
| info | 文档 Header/Query | GET + `Bearer` | 无 body | 启动时 AuthBootstrap | ⚠️ 请后端确认支持 **GET** |
| resetPassword | POST | ✅ 一致 | `{ email, code, newPassword }` | ResetPassword | ✅ |

**登录成功 `data` 字段**：前端使用 `userId`、`email`、`username`、`registerTime`、`token`、`refreshToken`（与文档一致）。

**错误处理**：`json.code !== 200` 时抛出 `UserApiError`，页面展示 `msg`（对应文档 400/401/500/503 等）。

**Mock 开关**：`.env.development` 中 `VITE_USE_MOCK=true` 时不请求后端（演示密码/验证码 `123456`）。

## 三、按页面：进入页面时要拉什么数据

| 页面 | 进入时建议请求 | 用户操作时建议请求 |
|------|----------------|-------------------|
| Login | 无 | 登录 / 发验证码 |
| Home | 可选 GET profile | 提交背景 → 生成路径/画像 |
| Chat | GET sessions；选中会话 GET messages | 发消息 → stream；上传；反馈 |
| Profile | GET profile | POST patch 更新画像 |
| Path | GET learning-path | PUT resource-status |
| Resource/:id | GET resources/:id | 无（导出若需要另议） |
| Exercise/:id | GET exercises/:id | POST submit |
| Analytics | GET overview + weak-points + suggestions | 切换时间 range 重新 GET |
| Settings | GET profile 或 user/me | POST logout |
