## 〇、user-service 认证对照（端口 `8001`）

基础路径：`/api/user` · 响应：`{ code, msg, data }` · 以 **`code === 200`** 判断成功

| 功能 | 方法 | 路径 | 请求体 / 鉴权 | 页面/调用 |
|------|------|------|---------------|-----------|
| 发注册验证码 | POST | `/api/user/sendRegEmailCode` | `{ email }` | Register |
| 注册 | POST | `/api/user/register` | `{ email, username, password, code }` | Register |
| 发登录验证码 | POST | `/api/user/sendLoginEmailCode` | `{ email }` | Login 验证码 Tab |
| 邮箱密码登录 | POST | `/api/user/login` | `{ email, password }` | Login 邮箱密码 |
| 用户名登录 | POST | `/api/user/loginByUsername` | `{ username, password }` | Login 用户名 |
| 验证码登录 | POST | `/api/user/loginByEmailCode` | `{ email, code }` | Login 验证码 |
| 用户信息 | GET | `/api/user/getUserInfo` | `Authorization: Bearer` | AuthBootstrap |
| 刷新 token | POST | `/api/user/refreshToken` | Header Bearer，**无 body** | `refreshToken()` 已封装，页面未自动调用 |
| 发重置验证码 | POST | `/api/user/sendResetEmailCode` | `{ email }` | ResetPassword |
| 重置密码 | POST | `/api/user/resetPwd` | `{ email, code, newPassword }` | ResetPassword |

**登录成功 `data`**：`userId`、`email`、`username`、`registerTime`、`token`、`refreshToken`  
**注册成功 `data`**：无 token，前端跳转 `/login`  
**错误**：`json.code !== 200` → `UserApiError`，页面展示 `msg`（含 400/401/422/503 等）

**Mock**：`.env.development` 中 `VITE_USE_MOCK=true` 时不请求后端（演示密码/验证码 `123456`）

**后端文档**：`backend/user-service/frontend-handoff.md`（一页纸）、`frontend-api.md`（全量）

## 一、需要和 backend 对齐的内容（给后端同学）

| 序号 | 内容 | 说明 |
|------|------|------|
| 1 | API 根地址与端口 | **user-service：`8001`**；agent：`8003`；Vite 代理 `/api` |

| 7 | OpenAPI | http://127.0.0.1:8001/docs |

详细路径见 **[BACKEND_INTEGRATION.md](./BACKEND_INTEGRATION.md)**（全站）；认证以 user-service 文档为准。
