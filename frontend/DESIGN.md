# 智慧学习中心 · 前端设计规范（DESIGN.md）

> 本文件为前端 UI 的**视觉约束文档**。干活前请先读本文，再改样式与页面。  
> 参考来源：[awesome-design-md](https://github.com/VoltAgent/awesome-design-md)（Stitch DESIGN.md 思路）+ 赛题配色（科技蓝 #165DFF、教育绿 #36D399）。

---

## 1. 视觉气质

- **定位**：高等教育个性化学习平台，专业、清晰、可信赖，略带科技感。
- **密度**：中等留白，信息分层明确，避免拥挤。
- **动效**：轻量（入场、悬停、背景遨游），遵守 `prefers-reduced-motion`。
- **禁止**：过度圆角（胶囊形大框）、实心大白块挡住背景、花哨渐变字以外的杂乱配色。

---

## 2. 色彩（语义色）

| 角色 | 色值 | 用途 |
|------|------|------|
| Primary | `#165DFF` | 主按钮、链接、强调数字、品牌渐变起点 |
| Accent | `#36D399` | 成功、次要强调、品牌渐变终点 |
| Surface | `#F9FAFB` | 页面底色（登录后内页） |
| Text Primary | `#1D2129` / `#1A1A1A` | 标题、正文 |
| Text Secondary | `#4E5969` ~ `#5C5C5C` | 说明、副标题 |
| Text Muted | `#86909C` ~ `#8A8A8A` | 辅助、占位 |
| Border | `#E5E7EB` | 分割线（内页） |
| Glass Card | `rgba(255,255,255,0.36)` + `blur(24px)` | 统计格、能力卡、流程卡（须能透出背景） |
| Glass Shell | `rgba(255,255,255,0.05)` + 描边 | 平台能力 / 使用流程**外框**（勿铺厚白底） |

深色模式：表面 `#111827`，玻璃卡片 `rgba(17,24,39,0.42)`，保持同等语义。

---

## 3. 字体

- **中文**：`"Noto Sans SC"` 优先，回退 PingFang SC、Microsoft YaHei。
- **层级**：
  - 页面主标题：clamp(1.875rem, 4.5vw, 2.5rem)，字重 600
  - 区块标题：1rem，字重 600，字间距略加
  - 卡片标题：0.875rem，字重 600
  - 正文：0.8125rem ~ 1rem，行高 1.65~1.8
  - 辅助：0.75rem 及以下

---

## 4. 组件

### 品牌 Logo（顶栏）

- **必须**：`linear-gradient(135deg, #165DFF, #36D399)` 方块 + **白色** 图标（`GraduationCap`）。
- **禁止**：毛玻璃底 + 蓝色线框图标（与能力卡图标样式混淆）。

### 按钮

- 主按钮：蓝绿渐变、白字、圆角约 10px（`.landing-btn-glass` 或 `.btn-primary`）。
- 次按钮：浅底 + 主色描边/文字。

### 毛玻璃卡片（`.landing-glass-card`）

- 背景 `rgba(255,255,255,0.36)`，`backdrop-filter: blur(24px) saturate(1.4)`。
- 边框 `1px solid rgba(255,255,255,0.92)`，内高光 `inset 0 1px 0 rgba(255,255,255,0.85)`。
- 圆角 **10px**（`0.625rem`），悬停略提亮，勿改为不透明实心白。

### 区块外框（`.landing-section-frame`）

- 仅轻透明壳：`background: rgba(255,255,255,0.05)`，**不要**与内卡同叠 36% 白底。
- 圆角：**10px**（移动）/ **12px**（≥768px），禁止 ≥16px 大圆角。
- 内层小卡与统计区使用**同一套** `.landing-glass-card` 参数。

### 能力卡图标

- 四色区分：蓝 / 绿 / 紫 / 橙（`.landing-icon-tone--*`），勿全部统一为蓝色玻璃底。

---

## 5. 布局与间距

- 门户主栏最大内容区宽屏侧栏布局（`landing-layout`）。
- 卡片间距：0.75rem ~ 1rem；区块间距：1.25rem。
- 顶栏：毛玻璃条 + 「登入 / 注册」→ `/login`（勿随 localStorage 改文案）。

---

## 6. 全站背景「遨游书海」

- **挂载**：`App.tsx` 根级 `<BookSeaBackground />`，**所有路由页面**共用（门户、登录、登录后内页、404）。
- **页面衬底**：各页根容器加 `.app-page-scrim`（半透明 Surface），保证正文可读且能透出书本；**禁止**实心 `bg-surface` 盖住书海。
- **意象**：书本在全屏空间中**缓慢漂浮**（水平漂移 + 轻微上下起伏）；**禁止**中心隧道、放射线、书本向镜头冲出的透视。
- 数量：移动约 20 / 桌面约 34；漂移极慢。
- `book-sea__veil` 轻透，勿加厚到看不见书；内页卡片仍用毛玻璃透出背景。

---

## 7. Do / Don't

| Do | Don't |
|----|--------|
| 外框轻透 + 内卡毛玻璃透出背景 | 双层 36%+44% 白底叠成实心块 |
| 顶栏 Logo 渐变底白图标 | 把 Logo 做成能力卡同款玻璃图标 |
| 圆角 10~12px（大框） | 20px+ 夸张圆角 |
| 门户不写「3 轮免费」等体验次数文案 | 在主页强调访客轮次限制 |
| 用 Lucide 图标、项目语义色 | 随意引入其它图标库风格 |

---

## 8. 响应式

- 断点：640 / 768 / 1024 / 1280（与现有 Tailwind 用法一致）。
- 移动端：侧栏隐藏或折叠，统计/能力改为 1~2 列。

---

## 9. 实现映射（代码）

| 规范 | 文件 |
|------|------|
| 设计 token、玻璃、门户 | `src/index.css` |
| 门户页结构 | `src/pages/Landing.tsx` |
| 遨游书海（全站） | `src/components/background/BookSeaBackground.tsx`（`App.tsx` 挂载） |
| 页面衬底 | `.app-page-scrim` in `src/index.css` |
| 登录页 | `src/pages/Login.tsx` |

改 UI 时**只改必要文件**，保持与本文一致；若需新 token，同步更新 `@theme` 与 `:root`。
